## 30 秒版本

**MCP = 给 LLM 应用用的「USB-C 接口」。**

- 以前：每接一个数据源（GitHub、数据库、本地文件）就要为每个 AI 应用单独写一次集成，M × N 的工作量。
- 现在：数据源写一个 **MCP Server**，AI 应用实现一个 **MCP Client**，双方按同一份协议说话，变成 M + N。

```
   没 MCP（M × N 条胶水代码）              有 MCP（M + N）
   ┌────────┐ ┌────────┐ ┌────────┐      ┌────────┐ ┌────────┐
   │ IDE AI │ │ 聊天App │ │ Agent  │      │ IDE AI │ │ 聊天App │
   └──┬──┬──┘ └──┬──┬──┘ └──┬──┬──┘      └───┬────┘ └───┬────┘
      │  │       │  │       │  │             │          │
   ┌──┴──┴───────┴──┴───────┴──┴──┐       ┌──┴──────────┴──┐
   │  GitHub  DB  文件  Slack ...  │       │  MCP 协议(JSON-RPC)│
   └──────────────────────────────┘       └──┬────┬────┬────┘
                                             │    │    │
                                        ┌────┴┐ ┌─┴──┐ ┌┴────┐
                                        │GitHub│ │ DB │ │文件 │
                                        │Server│ │Srv │ │Srv  │
                                        └──────┘ └────┘ └─────┘
```

## 一句话记住三个角色

| 角色 | 是什么 | 例子 |
| --- | --- | --- |
| **Host** | 用户直接用的那个应用，负责**征得用户同意**、调用 LLM | Claude Desktop、VS Code、Cursor、你自己的 Agent |
| **Client** | Host 内部为「一个 Server」开的一条连接 | Host 里连了 3 个 Server 就有 3 个 Client |
| **Server** | 提供能力的一端：工具、资源、提示词 | 你即将写的 `server.py` |

> 记住：**Host : Client : Server = 1 : N : N**。
> Client 是"连接"，不是"应用"。
